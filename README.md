# DataBase configuration
Create a my sql database using mysql workbench. Use the username name: "root" password: "password1234" and the database name: "synoptic_project"
On settings in vscode go to extensions and install mysql
In the terminal type "npm install mysql2"
Enter node database_setup.js this creates a schema for the customer information
If you add a database to the project please copy the layout of the code in database setup in the adding new table section.
Change the table name in the variable check table query in your part of the code.
